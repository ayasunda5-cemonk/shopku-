# 🛒 ShopKu - E-Commerce Mini

Website e-commerce sederhana dengan tema Shopee, database JSON, dan checkout via WhatsApp.

## ✨ Fitur
- 🎨 Tema warna ala Shopee (orange)
- 📱 Responsive (mobile & desktop)
- 🔍 Pencarian produk real-time
- 🗂️ Filter kategori
- 🛒 Keranjang belanja interaktif
- 💬 Checkout langsung ke WhatsApp (0851-5611-6154)
- 📦 Database produk via JSON

## 🚀 Deploy ke Vercel

1. Push ke GitHub:
```bash
   git init
   git add .
   git commit -m "Initial commit: ShopKu e-commerce"
   git branch -M main
   git remote add origin https://github.com/USERNAME/shopku.git
   git push -u origin main
```

2. Buka https://vercel.com → Import Git Repository → Pilih repo `shopku`
3. Framework Preset: **Other**
4. Klik **Deploy** ✅
